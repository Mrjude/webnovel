# 第一卷：野谶

> 洛阳 | ch-001 ~ ch-016 | 约 4.3 万字

## 卷名释义

**野谶**：不入兰台名录的术式。在本卷中，它既指那枚玉简，也指姜照自己——一个不该存在的、活着的未名录术式载体。

## 核心任务

1. 立世界：术式 / 符枢 / 兰台 / 谶律，通过**日常使用**而非讲解呈现
2. 立人设：姜照的实用主义、刻痕、代价
3. 抛主线：汉谶将崩的第一条线索
4. 得道具：那枚玉简（帝术残篇之一）

## 卷情感弧

**从"活着就行"，到"我要在忘光之前找到答案"。**

开篇的姜照是一个已经放弃追问的人——他每天洗谶、收钱、刻一刀，像在给自己倒计时。玉简的出现，第一次让他意识到：**他忘掉的那些东西，可能本来是有答案的。**

## 三段结构

### 第一段：瓦市（ch-001 ~ ch-006）

**功能**：日常 → 异常 → 崩塌

| 章 | 作用 |
|----|------|
| 001 | 开篇刻痕。洗谶第一单，展示观谶与代价。埋下"拓下来的野谶纹路眼熟" |
| 002 | 阿琅出场，零件铺。交代机关枢 / 失魂 / 焦尾。两人第一次互相试探 |
| 003 | 缇骑封市搜简。曹休首次露面，盘查姜照。假纹失效——汉谶裂隙的初次征兆 |
| 004 | 死客夜奔。野谶客撞进铺子，塞简，说"去找卧龙"，死。缇骑围上 |
| 005 | 阿琅听出异样；姜照第一次观简，发现与枢中术式同源。昏死 |
| 006 | 醒来，忘了母亲的脸。墙上的字条。刻第33刀。曹休破门："从今晚起，你是个死人了" |

**段末状态**：姜照从"旁观者"变成"当事人"，且已经是谶律第三条下的死人。

### 第二段：追猎（ch-007 ~ ch-012）

**功能**：逃 → 反制 → 代价升级

| 章 | 作用 |
|----|------|
| 007 | 从瓦市地下窑道逃出。阿琅相助，第一次并肩 |
| 008 | 被困，第一次动用枢中那道术式。威力惊人，自己也差点枢崩 |
| 009 | 老陶亮明身份（前兰台录谶官），讲出"汉谶将崩"的第一条线索 |
| 010 | 曹休的追猎逻辑展现。他不是要杀姜照，是要那枚简。双方第一次正面交锋 |
| 011 | **卷一爽点高潮**：姜照观曹休的机关枢术式，找到谶眼，破其一道卿术 |
| 012 | 代价落地。他烧掉了"为什么自己要找那个人"的记忆。第一次动摇 |

**段末状态**：赢了，但赢的代价让他开始怀疑整件事值不值得。

### 第三段：出洛阳（ch-013 ~ ch-016）

**功能**：真相 → 决断 → 上路

| 章 | 作用 |
|----|------|
| 013 | 阿琅的秘密：她的机关臂里藏着东西。她也在找卧龙 |
| 014 | 潜入天枢台外围。第一次见到汉谶实体，目睹全城"失谶"三息 |
| 015 | 曹休开条件：交简，保他进兰台。姜照假意答应。老陶死 |
| 016 | 出洛阳。隆中，竹林，摇羽扇的年轻人点破他的秘密 |

**段末状态**：上路。带着简、阿琅、三十七道刻痕，和一个必须去隆中的理由。

## 卷末收束

- 玉简在姜照手上（三块残片之一）
- 阿琅同行，身份未揭
- 老陶死，留下地道与一句遗言
- 曹休未死，也未放弃——他会一路追到襄阳
- **"卧龙"仍是个谜**

## 未闭合问题（引导卷二）

1. 姜照枢里那道术式到底是什么？
2. 他为什么要找"那个人"？（记忆被烧，他现在不知道了）
3. 卧龙是一个人，还是一套东西？
4. 阿琅的机关臂里藏着什么？
5. 老陶死前说的那半句话是什么？
